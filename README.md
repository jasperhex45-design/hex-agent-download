# HEX · 下载与试用

HEX 是配合 Codex 等支持 MCP 的宿主使用的视觉创作助手，帮助梳理出图需求、寻找参考、组织提示词并根据反馈调整。HEX 本身不是图像生成模型。

## 下载 dev8 试用版

- [Windows 64 位](https://github.com/jasperhex45-design/hex-agent-download/raw/refs/heads/main/HEX-Windows-x64-dev8.zip)
- [Mac · Apple 芯片](https://github.com/jasperhex45-design/hex-agent-download/raw/refs/heads/main/HEX-macOS-apple-silicon-dev8.tar.gz)
- [Mac · Intel 芯片](https://github.com/jasperhex45-design/hex-agent-download/raw/refs/heads/main/HEX-macOS-intel-dev8.tar.gz)

解压后阅读包内的使用说明。请将完整文件夹放在固定位置，并确保已安装 Codex 命令行。安装之前先检查自己是否已有 HEX 服务，以免产生重复配置。

## 使用前请知晓

- 此版本供测试：自动测试和基础启动检查已通过，但尚未完成其他用户电脑上的完整安装与真实出图验收。
- Mac 版本尚未经过 Apple 开发者签名和公证，macOS 可能阻止运行；请根据系统提示自行判断。
- 程序经过编译，仍可能被逆向；运行所需的说明与知识文件可读。
- 用户数据默认保存在用户主目录下的 `.hexagent`，迁移或卸载前请保留。
- HEX 编译试用包允许非商业使用和测试；未经授权不得转发、修改或商用。可以分享本下载页面链接。完整条款和第三方许可见包内文件。
