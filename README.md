# HEX Agent

把一句模糊的想法，变成你真正想要的图。

HEX Agent 是 Codex 里的视觉创作搭档。

**懂你要什么**　不只听你说了什么。它会从用途、场合和观众出发，只追问推不出来的那一点。

**有审美**　先找到真正贴合需求的参考，再动笔。

**懂模型**　Codex 自带生图就直接出图给你看；想用 Midjourney 等其他工具，它会按那个工具的写法给你提示词。

**越用越懂你**　从你的反馈里记住口味，下一张更准。
